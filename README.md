# Volleyball Legends Hitbox

Streamproof hitbox for Volleyball Legends. Matcha executor.

- Hitbox toggle (F1) and size to 70
- Visible or **Streamproof** mode (ball stays normal size)
- Ball transparency
- Jump assist
- Eye lines
- Dark graphics
- Profiles, auto-save, reset

Execute `v3.0.lua`, open the menu, tab **VBL**.
